在创建第一个 [Kotlin Notebook](kotlin-notebook-overview.md) 之前，您需要先设置环境。

## 设置环境

Kotlin Notebook 依赖于 [Kotlin Notebook 插件](https://plugins.jetbrains.com/plugin/16340-kotlin-notebook)。

要使用 Kotlin Notebook，请下载并安装 [IntelliJ IDEA 2026.1 或更早版本](https://www.jetbrains.com/idea/download/other/)。

如果 Kotlin Notebook 功能不可用，请确保插件已启用：

1. 在 IntelliJ IDEA 中，选择 **IntelliJ IDEA | 设置 | 插件**。
2. 在 **已安装 (Installed)** 选项卡中，找到 **Kotlin Notebook** 插件，并勾选插件名称旁边的复选框。

   ![安装 Kotlin Notebook](kotlin-notebook-plugin.png){width=700}

3. 点击 **确定 (OK)** 以应用更改，并根据提示重启 IDE。
